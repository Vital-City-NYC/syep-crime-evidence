This table profiles individual peer-reviewed evaluations underlying the J-PAL review, plus selected supplementary studies. Effect sizes are reported as percentage reductions on the headline criminal-justice outcome from each paper; some studies report multiple outcomes — see the expanded row for detail. These percentages are reductions relative to each study’s control-group baseline rate; because some baseline rates (such as juvenile incarceration) are very low, a large percentage reduction can reflect a small absolute change. Where a study reports both intent-to-treat and treatment-on-the-treated (complier) effects, the larger complier effect is noted in the expanded row.
